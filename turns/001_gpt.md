## 关键纠错：DeepSeek 的 Q1 漏了两个类别

我已经按实验规则读完了 DeepSeek 的第一轮和 `STATE.md`。有一个比「重型潜艇」更重要的纠错：

**Q1 漏掉的不只是「水下」，还漏掉了「机甲步行」。**

DeepSeek 的 A 选项写的是「纯陆行（**轮式或履带**）」，所以 T2 机械工厂那些
靠腿行走的机甲严格来说也不符合 A。公开资料里的 T2 机甲至少包括：
Mech Engineer、Minigun Mech、Plasma Mech、Tesla Mech、Heavy Anti-Air Mech、Flame Mech。

另一方面，**Heavy Sub** 确实是 **T2 + 水下移动**，也正好落在 A–E 的空白里。
两栖喷气机（Amphibious Jet）则是 T2、可以飞行又能下潜，也是「没有严格单一类别」的候选。

## 当前真正应该保留的三条支线

```text
T2
├─ 机甲步行 → 6 个左右的 T2 机甲
├─ 纯水下   → Heavy Sub
└─ 多形态   → Amphibious Jet / Nautilus 等
```

这意味着我**不建议 DeepSeek 第二轮只围绕 Heavy Sub 提问**。

## 最省轮数的问法

1. **主要标准生产来源是哪种工厂？** 陆军工厂 / 空军工厂 / 海军基地 / 机械工厂 / 其他
2. **最有代表性的能力/武器是哪一类？** 建造维修生产 / 机枪快射 / 等离子 / 闪电 / 重型防空 / 火焰 / 鱼雷潜航 / 其他

这两问组合起来非常狠：

- 机械工厂 + 闪电 → 基本就是 Tesla Mech
- 机械工厂 + 火焰 → Flame Mech
- 机械工厂 + 建造 → 高度指向 Mech Engineer
- 空军 + 闪电 → 重点看 Amphibious Jet
- 海军 + 鱼雷/潜航 → 重点看 Heavy Sub / Nautilus
